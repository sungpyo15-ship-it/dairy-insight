# 낙농 시장정보 앱 「DAIRY INSIGHT」 기획서 (v0.1)

> 작성일 2026-11-24 · 표기 원칙: **[확인]** 공식 자료로 확인 가능한 사실 / **[추정]** 가정·추정치 (실행 전 재확인 필요)

---

## 1. 핵심 결론

1. **앱 자체로 돈을 벌 생각은 접고, '리드(상담 신청) 확보 도구'로 설계해야 한다.** 국내 낙농가는 약 4천 호대 **[추정, 통계청 가축동향 확인 필요]**로 시장이 작아 유료 구독·광고 모델은 성립하기 어렵다. 앱의 가치는 "농가가 매주 들어오게 만들고 → 계산기로 문제를 숫자로 보여주고 → 상담·첨가제 판매로 연결"하는 데 있다.
2. **처음부터 네이티브 앱(iOS/Android)을 외주 개발하지 말 것.** 설치 장벽이 크고 비용 대비 검증이 안 된다. **PWA(웹앱) + 카카오톡 채널 주간 시황**으로 3~6개월 검증 후, 주간 재방문 농가가 일정 수준(예: 300호)을 넘을 때 네이티브 전환을 검토한다.
3. **차별점은 '시세 나열'이 아니라 '내 농장 손익으로 환산'이다.** 원유가·사료원료·환율·송아지값은 낙농진흥회, 축산신문, 단톡방에서 이미 볼 수 있다. 경쟁 정보원이 못 하는 것은 **IOFC(사료비 제외 수익)·첨가제 ROI·손익분기 유량** 계산과 컨설턴트의 해석이다.
4. **겸업·이해상충 검토가 개발보다 먼저다.** 재직 중인 사료회사의 거래처 정보·단가·영업자료를 활용하면 영업비밀·경업 문제로 직결된다(§6).

## 2. 제공 정보와 데이터 출처

| 구분 | 지표 | 1차 출처 | 갱신 | 수집 방식 |
|---|---|---|---|---|
| 국내 원유 | 원유 기본가격(음용유·가공유), 용도별 차등가격제 물량 | 낙농진흥회 | 연 1회 | 수동 입력 |
| 국내 원유 | 원유 생산량·유제품 재고·수급 | 낙농진흥회 낙농통계 | 월간 | 수동/스크래핑(이용약관 확인) |
| 생산비 | 우유 생산비(원/L), 사료비 비중 | 통계청 축산물생산비조사(KOSIS) | 연간 | KOSIS OpenAPI |
| 사육 현황 | 젖소 사육두수·농가 수 | 통계청 가축동향조사 | 분기 | KOSIS OpenAPI |
| 가축 시세 | 젖소 수송아지(초유떼기), 육우 송아지 | 농협 축산정보센터 | 주간 | 수동 입력 |
| 가축 시세 | 젖소·육우 도체 경락가 | 축산물품질평가원(축산유통정보) | 일간 | 공공데이터포털 API |
| 해외 유제품 | GDT 가격지수, 품목별(WMP·SMP·버터) | Global Dairy Trade | 격주 | 수동 입력(공개 결과) |
| 해외 유제품 | 미국 Class III/IV 유가 | USDA AMS | 월간 | USDA API |
| 사료 원료 | 옥수수·대두박 선물 | CME Group | 일간 | 유료 데이터 또는 지연시세 링크 **(재배포 라이선스 주의)** |
| 사료 원료 | 조사료(알팔파·티모시·연맥) 수입단가 | 관세청 수출입무역통계 | 월간 | 품목별 HS 코드 조회 |
| 거시 | 원/달러 환율 | 한국은행 ECOS | 일간 | ECOS OpenAPI |

**주의:** CME 선물가·GDT 품목 상세 등 일부 해외 데이터는 실시간/상세 수치의 **재배포가 제한**된다. 공공데이터도 '공공누리' 유형별 상업적 이용 조건이 다르다. 출시 전 출처별 이용약관 체크리스트를 반드시 만든다.

## 3. 기능 구성 (MVP → 확장)

| 단계 | 기능 | 마케팅 목적 |
|---|---|---|
| MVP (현재 시제품) | 시세 카드·추이 차트 / 주간 시황 브리핑 / 유대·IOFC 계산기 / 첨가제 투자 시뮬레이션 / 상담 신청 | 재방문 유도, 리드 확보 |
| 2단계 | API 자동수집(KOSIS·ECOS·축평원) / 카카오 알림톡 주간 발송 / 관리자 입력 화면 | 운영 공수 절감 |
| 3단계 | 검정성적(유량·유지방·유단백·체세포·MUN) 업로드 → 벤치마크 비교 / 번식지표(분만간격·공태일수) | 컨설팅 전환율 상승 |
| 4단계 | 자체 브랜드 첨가제 제품 페이지·실증 사례 / 대리점·수의사 파트너 전용 화면 | 판매 연계 |

**MUN·체세포·IOFC 같은 '문제 발견형' 지표가 상담 전환의 핵심**이다. 시세만 보는 앱은 정보 앱으로 끝난다.

## 4. 사업성 평가 **[추정 — 견적 비교 필요]**

### 4-1. 개발·운영 비용

| 항목 | 방안 A: 자체 PWA (본 시제품 확장) | 방안 B: 네이티브 앱 외주 |
|---|---|---|
| 초기 개발 | 0~500만원 (도메인·디자인 보완) | 3,000만~6,000만원 |
| 월 운영(서버·도메인) | 1~5만원 | 20~50만원 + 유지보수 |
| 앱스토어 | 불필요 | Apple 연 $99, Google 1회 $25 [확인] |
| 콘텐츠(주간 시황) | 주 2~3시간 본인 작성 | 동일 |
| 카카오 알림톡 | 건당 약 10원 내외 | 동일 |

### 4-2. 수익 연결 구조 (예시 시나리오)

- 가정: 주간 이용 농가 300호 → 상담 신청 연 30호(10%) → 첨가제·사료 거래 전환 10호
- 착유 60두 농가, 두당 일 400원 첨가제 → 농가당 연 약 876만원 매출, 유통마진 30% 가정 시 약 263만원
- **10호 전환 시 연 매출 약 8,760만원 / 매출총이익 약 2,630만원** → 방안 A는 1년 차 손익분기 가능, 방안 B는 개발비 회수에 2년 이상 [추정]

결론: **방안 A로 시작.** 핵심 KPI는 다운로드 수가 아니라 ① 주간 재방문 농가 수 ② 계산기 사용 수 ③ 상담 신청 수 ④ 거래 전환 수.

### 4-3. 경쟁 정보원과의 차별화

| 경쟁 정보원 | 강점 | 약점 → 우리의 기회 |
|---|---|---|
| 낙농진흥회·낙농육우협회 | 공신력, 원자료 | 해석·농장 단위 적용 부족 |
| 축산 전문지(축산신문, 농민신문 등) | 뉴스 속도 | 계산·맞춤 진단 없음 |
| 사료회사·집유주체 자체 자료 | 거래처 밀착 | 자사 고객 한정, 중립성 약함 |
| 카카오톡 단톡방·밴드 | 실시간, 신뢰 네트워크 | 정보 검증 안 됨 |

## 5. 예상 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 데이터 재배포 약관 위반 | 높음 | 출처별 약관 검토, 상세 선물가는 링크·주간 요약으로 대체 |
| 콘텐츠 갱신 중단(겸업으로 시간 부족) | 높음 | 주 1회 고정 발행, 자동수집 우선 개발, 템플릿화 |
| 개인정보(상담 신청) 관리 | 중간 | 수집 최소화, 동의·보관기간 명시, 개인정보처리방침 게시 |
| 첨가제 효능 표현 → 사료관리법 표시·광고 위반 | 높음 | 계산기는 '사용자 입력 가정치' 방식 유지, 제품 효능 문구는 등록 내용 범위 내에서만 |
| 앱이 특정 회사 영업도구로 보여 신뢰 저하 | 중간 | 시황은 중립적으로, 제품 소개는 별도 메뉴로 분리 |

## 6. 겸업·이해상충 체크리스트 (개발 착수 전 필수)

- [ ] 재직 회사 취업규칙·근로계약서의 **겸업 금지/사전승인** 조항 확인
- [ ] 이 앱이 **회사 마케팅 프로젝트인지, 개인 사업인지** 명확히 결정 (회사 프로젝트라면 회사 자산으로 귀속, 개인 사업이라면 회사 자원·시간 사용 금지)
- [ ] 회사 거래처 명단·단가·배합비·내부 시장자료를 앱 데이터나 영업에 **사용하지 않음**
- [ ] 경업금지 약정(퇴직 후 포함) 존재 여부 및 범위
- [ ] 개인 사업 시 사업자등록·통신판매업 신고 필요 여부

## 부록: 시제품 실행 방법

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (휴대폰에서 '홈 화면에 추가' 시 앱처럼 설치)
```

데이터는 `data/market.json`만 수정하면 화면 전체에 반영된다. **현재 수치는 화면 확인용 샘플이며 실제 시장 수치가 아니다.**
