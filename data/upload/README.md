# 유대 정산 기준 엑셀 올리는 곳

1. 앱 더보기 → 계산기 → **양식 내려받기** (또는 저장소의 `templates/유대정산표_양식.xlsx`)
2. 유업체별 유대정산표를 양식의 5개 시트(단가·유지방·유단백·체세포·세균)에 옮겨 적습니다.
3. 이 폴더에 `.xlsx` 파일로 올립니다 (GitHub 웹: Add file → Upload files → Commit changes).
4. 올리면 자동 수집 작업이 바로 실행되어 1~3분 뒤 앱 계산기의 납유처 목록에 반영됩니다.

- 여러 파일을 올리면 파일 이름순으로 읽고, 같은 유업체는 뒤 파일 값으로 바뀝니다.
- 값이 잘못된 유업체는 건너뛰고, 앱의 더보기 → 데이터 상태에 경고가 표시됩니다.
- 이 폴더의 파일은 저장소에 공개됩니다. 고객 목장 정보나 내부 자료는 넣지 마세요.
